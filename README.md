## About The Project

DV Weather Editor is a mod that exposes the game's built-in weather editor, allowing you to manually control weather conditions while playing. By itself this mod does not add or control any of the systems you see when toggling this feature. It's purely for enabling the already existing system!

### Features

- Toggle the in-game weather editor GUI with a configurable key binding (default: **F7**)
- Key binding is configurable via the Unity Mod Manager settings panel
